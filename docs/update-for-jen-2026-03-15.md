## How to Edit Pages

1. Go to **https://otyokwah.vercel.app/keystatic**
2. Log in with the **blceditor** GitHub account
3. Click **Pages** in the sidebar → click any page to edit
4. Make changes → click **Save** at the top
5. Changes appear on the site within a few seconds

The editor supports rich text, images, and all the camp-specific components (session cards, CTA buttons, galleries, etc.).
